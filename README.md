# Catálogo CEA: archivos de distribución

Este repositorio contiene paquetes cifrados y el mini instalador de Catálogo CEA.

Para instalar, usá el enlace personal entregado por el vendedor y conservá el nombre del archivo descargado. El instalador descarga los documentos, instala el programa y activa una licencia permanente para esa PC. Se necesita Internet durante la instalación; después, el catálogo puede usarse sin conexión.

Los paquetes `.ceap` se utilizan desde el asistente. No se abren manualmente. Este repositorio no contiene claves privadas, permisos personales ni los documentos sin cifrar.

Windows 10 de 64 bits fue probado. La compatibilidad con Windows 7 SP1 de 64 bits está pendiente de prueba en un equipo real.
